# Order Cancellation Policy

## Eligibility

Orders may be cancelled only while their status is "processing".

Once an order has entered "packed", "shipped", "delivered", or "cancelled" status, it cannot
be automatically cancelled.

## Customer Verification

Before processing a cancellation request, the customer must provide:

- the order number
- the email address associated with the order

Both values must match the stored order information.

## Automatic Cancellation

The customer-support agent may submit a cancellation only when:

1. the customer has been successfully verified, and
2. the order status is exactly "processing".

Cancellation eligibility is enforced by the order service and must not be decided solely by
the language model.

## Orders That Cannot Be Cancelled

If an order is already packed or shipped, support should explain that cancellation is no
longer available.

If appropriate, the customer may be advised to wait for delivery and follow the standard
Returns & Refunds Policy.

## Uncertain Order State

If order status cannot be retrieved or appears inconsistent, the support agent must not
attempt a cancellation.

The request must be escalated for manual review.
